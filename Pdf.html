Tentang ELKA

ELKA dibuat sebagai platform sederhana untuk membantu pengguna mengelola dokumen PDF dengan cepat. Semua pemrosesan dilakukan secara lokal di browser jika fitur mendukung pemrosesan lokal, sehingga file Anda tidak perlu diunggah ke server.

ELKA menyediakan berbagai tool untuk menggabungkan, memisahkan, mengonversi, mengedit, mengamankan, dan mengoptimalkan PDF — semuanya dalam satu tempat.

Help & FAQ

Panduan penggunaan dan pertanyaan umum

Bagaimana cara kerja ELKA?

ELKA memproses file PDF Anda langsung di browser menggunakan JavaScript. File tidak diunggah ke server kami, sehingga privasi Anda terjaga. Namun, karena pemrosesan dilakukan di perangkat Anda, kinerja bergantung pada spesifikasi perangkat dan ukuran file.

Apakah file saya aman?

Ya. File diproses secara lokal di browser Anda. Kami tidak menyimpan atau mengirim file Anda ke mana pun. Saat Anda menutup halaman atau membersihkan workspace, referensi file akan dihapus dari state aplikasi.

Fitur apa saja yang tersedia?

ELKA menyediakan tool untuk Organize (Merge, Split, Extract, Rotate, Delete, Reorder), Convert (JPG/PNG→PDF, PDF→JPG/PNG/Text), Edit (Edit PDF, Annotate, Watermark, Page Number, Fill PDF), Security (Protect, Unlock), Optimize (Compress, Optimize), serta Utilities (Viewer, Metadata, Information, Compare, Print).

Kenapa Protect/Unlock PDF terbatas?

Enkripsi PDF yang benar membutuhkan library kriptografi yang kompleks. ELKA menggunakan pdf-lib yang memiliki dukungan terbatas untuk enkripsi. Kami tidak akan mengklaim PDF terenkripsi jika sebenarnya tidak. Untuk Protect PDF, kami menggunakan metode yang didukung library. Untuk Unlock, kami hanya memproses PDF yang memang bisa dibuka tanpa password atau dengan password yang benar.
